# 운동 추천 AI 모델 상세 문서

## 1. 개요

본 시스템은 사용자의 기본 신체 정보(나이, 성별, 키, 체중, BMI)를 입력받아  
머신러닝 기반 모델이 적합한 운동 카테고리를 예측하고,  
CSV 파일에 포함된 실제 운동 루틴 데이터를 분석하여  
**준비운동 1개, 본운동 2개, 정리운동 1개**  
총 4개의 운동 루틴을 자동 추천하는 AI 기반 운동 추천 서비스입니다.

해당 문서에서는 데이터 준비, 전처리, 모델 학습, CSV 파싱, 추천 알고리즘 전체 구조를 상세하게 설명합니다.

---

## 2. 사용된 데이터

### 2.1 원본 데이터 설명

공공데이터 포털에서 제공되는 **체력측정 및 운동처방 종합 데이터(약 30만 건)**을 사용하였습니다.

원본 CSV는 50개 이상의 컬럼으로 구성되어 있으며 다음 정보를 포함합니다.

- 신체 측정값(신장, 체중, 체지방률 등)
- 혈압, 악력, 윗몸 일으키기 등 체력 요소
- 성별, 연령, 측정 장소
- 운동처방 컬럼(`MVM_PRSCRPTN_CN`)

하지만 운동 추천 시스템이 사용하는 실제 컬럼은 단 하나입니다.

---

### 2.2 핵심 운동 루틴 컬럼: `MVM_PRSCRPTN_CN`

예시 데이터:

```
준비운동:정적 스트레칭 루틴프로그램 / 본운동:런지,스쿼트 / 정리운동:요가
준비운동:걷기 / 본운동:버피 테스트,윗몸 일으키기 / 정리운동:스트레칭
```

하나의 문자열 안에 **준비운동 / 본운동 / 정리운동** 루틴이 모두 포함된 형태입니다.

## 3. CSV 정제 과정

### 3.1 불필요한 컬럼 제거

추천 시스템은 오직 `MVM_PRSCRPTN_CN`만 필요하므로  
나머지 50개 이상의 컬럼은 모두 삭제합니다.

아래 스크립트는 필요한 컬럼만 남긴 새로운 CSV를 생성합니다.

```python
import pandas as pd
import os

def clean_csv(input_path, output_path):
    df = pd.read_csv(input_path, encoding="utf-8")
    df_new = df[["MVM_PRSCRPTN_CN"]].dropna()
    df_new.to_csv(output_path, index=False, encoding="utf-8")

if __name__ == "__main__":
    input_csv = "data/KS_NFA_FTNESS_MESURE_MVN_PRSCRPTN_GNRLZ_INFO_202503.csv"
    output_csv = "data/exercise_routine_clean.csv"
    clean_csv(input_csv, output_csv)
```

### 3.2 생성 결과물

```
data/exercise_routine_clean.csv
```

이 파일에는 **운동 루틴 문자열만** 포함됩니다.

## 4. 머신러닝 모델 설명

### 4.1 입력 데이터 구성

| Feature | 설명 |
|--------|------|
| group | 연령대(10대/20대/30대 등) |
| age | 실제 나이 |
| F | 여성 여부(1 또는 0) |
| M | 남성 여부(1 또는 0) |
| height | 키 |
| weight | 체중 |
| bmi | BMI |

### 4.2 타깃 라벨(운동 카테고리)

본운동 텍스트를 분석하여 다음 9개 카테고리를 자동 생성합니다.

- 하체근력
- 상체근력
- 코어
- 걷기
- 달리기
- 자전거
- 유연성
- 스트레칭
- 기타

텍스트 분석 함수 `classify_category()`를 통해 본운동 내용을 기반으로 카테고리를 분류했습니다.

### 4.3 모델 종류

**RandomForestClassifier**

장점:
- 비선형 데이터 학습 가능
- 다중 클래스 분류에 강함
- 데이터 불균형에도 비교적 안정적

### 4.4 모델 성능
(예시)

- Accuracy: 0.48  
- Macro F1: 0.19  

데이터 불균형으로 인해 스트레칭 데이터가 많지만  
본 시스템은 예측 후 CSV 기반으로 세분화된 운동을 추천하여 단조로움을 방지했습니다.

## 5. 운동 루틴 생성 로직

모델은 “운동 카테고리(예: 하체근력)”만 예측합니다.  
실제 추천되는 운동은 **CSV 데이터에서 직접 파싱**하여 구성합니다.

---

## 5.1 CSV 파싱 로직

각 행의 문자열을 다음 순서로 처리합니다:

1. "/" 기준으로 분할
2. 준비운동 / 본운동 / 정리운동 각각 분리
3. 본운동 문자열을 기반으로 운동 카테고리 자동 분류
4. 카테고리별 운동 목록(`category_routines`)에 저장

구조 예시:

```json
{
  "하체근력": {
    "준비운동": [...],
    "본운동": [...],
    "정리운동": [...]
  },
  "상체근력": {
    ...
  }
}
```

# 이 모델은 어떻게 추천되는가

이 모델은 **두 단계 구조**로 운동을 추천합니다.

---

## 1단계: 머신러닝 기반 운동 카테고리 예측

사용자로부터 다음 데이터를 가져옵니다:

| 입력값 | 의미 |
|--------|------|
| AGE | 나이 |
| GENDER | 성별 |
| HEIGHT | 키 |
| CURRENT_WEIGHT | 체중 |
| BMI | 체질량지수 |
| group | 연령대(20대=20, 30대=30 등) |

이 데이터를 입력 벡터로 변환:

```
[group, age, F, M, height, weight, bmi]
```

이 벡터를 모델에 넣으면 다음 중 하나가 예측됩니다.

- 하체근력
- 상체근력
- 코어
- 걷기
- 달리기
- 자전거
- 유연성
- 스트레칭
- 기타

예측 예시:

```
하체근력
```

---

## 2단계: 해당 카테고리 안에서 운동 루틴을 구성하여 추천

정제된 CSV는 다음과 같은 구조를 갖습니다.

```
준비운동:정적 스트레칭 / 본운동:런지,스쿼트,점프 / 정리운동:요가
```

여기서:

- 준비운동 리스트  
- 본운동 리스트  
- 정리운동 리스트  

를 카테고리별로 자동 수집합니다.

### 본운동 기반 카테고리 분류

예:
- 런지, 스쿼트, 점프 → 하체근력  
- 푸시업, 팔굽혀펴기 → 상체근력  
- 플랭크, 크런치 → 코어  

---

## 3단계: 추천 규칙

예측된 카테고리에서 다음 개수를 선택합니다.

- 준비운동: 1개  
- 본운동: 2개  
- 정리운동: 1개  

총 4개로 구성된 세트를 반환합니다.

이 구조는 전문 트레이너 루틴(워밍업 → 메인 → 쿨다운)과 동일합니다.

---

## 추천 전체 알고리즘 요약

1. 사용자 정보 조회  
2. 연령대 그룹 계산  
3. 입력 벡터 생성  
4. 모델이 운동 카테고리 예측  
5. CSV에서 해당 카테고리의 운동 리스트 찾기  
6. 준비운동 1개 선택  
7. 본운동 2개 선택  
8. 정리운동 1개 선택  
9. JSON 형태로 프론트에 반환
